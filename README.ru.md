# Climb

**[English](README.md) · Русский**

### Self-hosted панель для отслеживания крипто-кошельков, трат и капитала

Добавляете любой **публичный** адрес — Bitcoin, Ethereum, Polygon, Arbitrum, Base, Optimism,
TRON, Solana — и Climb превращает активность в блокчейне в финансовую панель: **себестоимость по
FIFO, реализованная и нереализованная прибыль**, траты по категориям, бюджеты, цели накопления,
автоматически найденные регулярные платежи, движение денег и живые курсы конвертации.

## Зачем это нужно

- **Настоящий P&L, а не просто балансы** — каждое поступление открывает лот, каждый расход
  закрывает лоты по FIFO. Вы видите среднюю цену входа, вложенную сумму, нереализованную и
  зафиксированную прибыль по каждому активу — сразу по всем кошелькам.
- **Только просмотр** — вы вводите публичный адрес и больше ничего. Climb негде хранить сид-фразу
  или приватный ключ, и он отклоняет всё, что на них похоже.
- **Данные не покидают вашу машину** — кошельки, транзакции и настройки лежат в вашем контейнере
  Postgres. Без аккаунтов, облака и телеметрии.
- **И про траты тоже** — категории, автоматические правила, определение переводов между своими
  кошельками, бюджеты с контролем темпа, цели накопления и автопоиск регулярных платежей.
- **Все сети на одном экране** — восемь блокчейнов, нативные монеты, стейблкоины ERC-20 / TRC-20 и
  токены SPL в одном портфеле.
- **Две темы, два языка** — тёмная и светлая, английский и русский, переключаются из бокового меню.
  Новый язык — это один новый файл.
- **Запуск одной командой** — `docker compose up -d`, и панель доступна на `localhost:8080`.

## Быстрый старт

```bash
git clone https://github.com/SpecFlowdev/climb.git
cd climb
cp .env.example .env      # необязательно — у всех значений есть рабочие умолчания
docker compose up -d
```

Откройте **http://localhost:8080**. Схема базы создаётся при первом запуске — отдельных
миграций запускать не нужно.

Хотите сразу увидеть заполненную панель? Поставьте `DEMO_MODE=true` в `.env` до первого запуска,
и Climb создаст реалистичный демонстрационный портфель.

```bash
docker compose logs -f app     # смотреть логи API
docker compose down            # остановить, данные сохранятся
docker compose down -v         # остановить и удалить том с базой
```

## Поддерживаемые сети

| Сеть | Монета | Токены | Источник данных |
| --- | --- | --- | --- |
| Bitcoin | BTC | — | Blockstream Esplora |
| Ethereum | ETH | ERC-20 (USDT, USDC, DAI…) | Blockscout |
| Polygon | POL | ERC-20 | Blockscout |
| Arbitrum One | ETH | ERC-20 | Blockscout |
| Base | ETH | ERC-20 | Blockscout |
| Optimism | ETH | ERC-20 | Blockscout |
| TRON | TRX | TRC-20 (USDT…) | TronGrid |
| Solana | SOL | SPL (USDC, USDT…) | Solana JSON-RPC |

Все источники работают без API-ключей: ключи нужны только чтобы поднять лимиты — добавьте их в
`.env`, если синхронизируете много кошельков. Цены берутся из CoinGecko, для стейблкоинов есть
запасное значение $1, поэтому панель не остаётся пустой при недоступности рынка.

## Возможности

**Дашборд**
- Реальный доход, расходы, баланс и норма сбережений за месяц или за весь год
- Сравнение с предыдущим периодом
- Кольцевая диаграмма расходов и список категорий
- Последние транзакции со ссылками в обозреватель, основные активы, кривая капитала за 90 дней

**Капитал и P&L**
- Общая стоимость, вложено (себестоимость), нереализованная и зафиксированная прибыль
- Таблица позиций: количество, средняя цена входа, текущая цена, стоимость, P&L, доля
- Разрез по сетям и по кошелькам
- Фильтр «пыли» — скрывает позиции дешевле $1

**Страница актива** (клик по любой позиции)
- Сколько держите, средняя цена входа, нереализованная и зафиксированная прибыль
- Все открытые FIFO-лоты: дата покупки, цена входа и текущая прибыль по каждому
- График цены за 90 дней, в каких кошельках лежит и вся история операций

**Бюджеты**
- Лимит на категорию — на месяц или на год
- Прогресс-бар с меткой темпа: сразу видно, тратите вы быстрее, чем идёт месяц, или нет
- Статус по каждой категории: в рамках / близко к лимиту / превышен

**Цели**
- Копить на количество монет (0.25 BTC) или на стоимость портфеля ($25 000)
- Кольцо прогресса, счётчик дней до срока и сумма, которую нужно откладывать в месяц

**Регулярные**
- Повторяющиеся платежи находятся автоматически — настраивать ничего не нужно
- Интервал, число повторов, дата следующего и оценка нагрузки в месяц

**Транзакции**
- Фильтры по кошельку, категории и направлению, поиск по адресу, хэшу и заметке
- Категория меняется прямо в таблице, ручные операции, удаление, экспорт CSV
- Переводы между своими кошельками определяются автоматически и не считаются расходом
- Комиссии учитываются отдельно от сумм

**Категории и правила**
- 15 встроенных категорий с русскими названиями плюс свои собственные
- Движок правил: поля `counterparty` / `asset` / `chain` / `note` / `direction`, условия
  «содержит» / «равно» / «начинается с», приоритеты
- Применение правил ко всей истории в один клик, ручные назначения сохраняются

**Аналитика**
- Доходы и расходы по месяцам, линия чистого потока
- Структура доходов и расходов
- Оборот по активам, средний / лучший / худший месяц

**Конвертер**
- Живые курсы между монетами и стейблкоинами
- График цены за 7 / 30 / 90 / 365 дней

**Настройки**
- Тёмная и светлая тема, английский и русский язык
- Режим приватности — размывает все суммы, удобно для скриншотов и созвонов
- Состояние инстанса: версия, число кошельков и транзакций, последняя синхронизация
- Полная очистка данных с подтверждением вводом

## Настройка

Всё задаётся через переменные окружения. Скопируйте `.env.example` в `.env` и меняйте нужное.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `APP_PORT` | `8080` | Порт, на котором публикуется панель |
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` | `climb` | Доступы к базе |
| `DATABASE_URL` | из compose | Полностью переопределяет строку подключения |
| `BASE_CURRENCY` | `usd` | Валюта оценки |
| `SYNC_INTERVAL_MINUTES` | `15` | Интервал фоновой синхронизации, `0` — выключить |
| `MAX_TX_PER_SYNC` | `200` | Максимум операций за одну синхронизацию кошелька |
| `PRICE_TTL_SECONDS` | `300` | Время жизни кэша цен |
| `DEMO_MODE` | `false` | Демо-портфель при первом запуске |
| `COINGECKO_API_KEY` | — | Необязательно, поднимает лимиты цен |
| `ETHERSCAN_API_KEY` | — | Необязательно |
| `TRONGRID_API_KEY` | — | Необязательно, поднимает лимиты TRON |
| `SOLANA_RPC_URL` | публичный RPC | Свой узел для больших объёмов |

## API

Фронтенд работает с обычным REST API — его удобно дёргать скриптами.

| Метод | Эндпоинт | Назначение |
| --- | --- | --- |
| `GET` | `/api/health` | Проверка живости |
| `GET` `POST` | `/api/wallets` | Список / добавление кошелька |
| `POST` | `/api/wallets/sync` | Синхронизировать все кошельки |
| `POST` | `/api/wallets/:id/sync` | Синхронизировать один кошелёк |
| `GET` | `/api/transactions` | Фильтры, поиск, постраничность |
| `GET` | `/api/transactions/export.csv` | Экспорт всей истории |
| `GET` | `/api/assets` | Позиции с себестоимостью и P&L |
| `GET` | `/api/assets/:symbol` | Один актив: FIFO-лоты, кошельки, история |
| `GET` `POST` | `/api/planning/budgets` | Бюджеты с тратами и темпом |
| `GET` `POST` | `/api/planning/goals` | Цели накопления с прогрессом |
| `GET` | `/api/planning/recurring` | Найденные регулярные платежи |
| `GET` `POST` | `/api/categories` · `/api/rules` | Категории и правила |
| `GET` | `/api/stats/summary` · `/categories` · `/cashflow` · `/portfolio` · `/networth` | Данные дашборда |
| `GET` | `/api/market/convert` · `/api/market/chart` | Курсы и история цен |
| `GET` `PUT` | `/api/settings` | Настройки инстанса |

## Разработка

```bash
# прогнать тесты (движок себестоимости FIFO)
cd server && npm test

# только база
docker compose up -d db

# API на :8080
cd server && npm install && npm run dev

# фронтенд на :5173 с проксированием /api
cd web && npm install && npm run dev
```

```
server/   API на Express + TypeScript, адаптеры сетей, планировщик синхронизации
  src/chains/     по адаптеру на сеть, все за одним интерфейсом
  src/services/   синхронизация, цены, категоризация, статистика, FIFO P&L, планирование
  src/routes/     REST-слой
  test/           юнит-тесты движка себестоимости
web/      Дашборд на React + Vite
  src/i18n/       en.ts, ru.ts — новый язык это новый файл
  src/pages/      по файлу на экран
```

**Как добавить язык:** скопируйте `web/src/i18n/en.ts`, переведите значения и зарегистрируйте файл
в `web/src/i18n/index.tsx`. Недостающие ключи автоматически берутся из английского.

## Безопасность

- Climb хранит **только публичные адреса**. Он никогда не запрашивает и не передаёт ключи и
  сид-фразы и отклоняет ввод, похожий на мнемоническую фразу.
- Контейнер работает от непривилегированного пользователя и открывает один HTTP-порт.
- Встроенной авторизации нет — панель рассчитана на `localhost` или на работу за вашим обратным
  прокси / VPN. Перед публикацией в интернет закройте её basic-auth или SSO-прокси.
